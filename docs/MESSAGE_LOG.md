# 本机消息日志

日志用于逐条查看收到的消息。当前 QQ 私聊和群聊支持文本、纯图片与图文：一条平台消息只计一条，多个图片附件不会拆行。来源、账号、会话分类、内容类型、接收时间、发送者与完整正文均可查看；详情提供事件 ID、会话 ID、发送时间和图片预览。尚不接入语音、视频、普通文件和频道事件。

## 启动

先按 QQ 接入文档完成本机绑定，再在根目录执行：

```sh
bun install --frozen-lockfile
bun run dashboard:build
bun run qq
```

访问 [本机日志页](http://127.0.0.1:3410)。保持 QQ 进程运行；首次默认只接收，模型回复由 [设置页](http://127.0.0.1:3410/settings) 的独立开关控制。已有 3410 端口进程时会明确失败，不自动切换端口或连接第二个机器人。

前端开发可另开终端执行 `bun run dashboard:dev`，访问 `http://127.0.0.1:5173`，API 代理到已启动的本机 QQ 进程。核心 Mock 开发入口 `bun run dev` 不启动日志服务，也无需数据库或 QQ 凭据。

## 列表行为

- 搜索正文、发送者、会话与事件 ID；筛选来源、私聊/群聊和文本/图片（包含图文），每页 25/50/100 条，默认 50 条。单一来源时省略来源筛选器。
- 默认实时展示：`GET /api/events` 通过 SSE 推送不含正文的变更通知，客户端自动读取最新记录并更新条数和处理状态。通知只在新记录或处理状态成功提交后触发，重复消息不新计数；每 5 秒同步连接状态。无需手动刷新或点击新消息提示。
- SSE 建连超过 5 秒或中断时，自动改用每秒读取，单次读取限时 5 秒；页面隐藏、主动暂停或卸载时清理连接和计时器。恢复实时或重新显示页面时自动补齐新记录。
- 历史分页沿用快照，避免新消息使翻页重复或跳行；正常实时首页不锁定旧快照。达到保留上限后，旧记录仍可能被淘汰。
- 支持深浅主题、自定义菜单键盘操作、加载/空/失败状态和横向滚动表格。完整字段与图片在详情侧栏展示，侧栏约束焦点，Escape 或外部点击关闭后恢复焦点；实时更新不会关闭已打开的消息。
- 消息内容只作为文字渲染，不作为 HTML 执行。未提供昵称时显示平台标识符，不猜测用户身份。时间按浏览器本地时区显示，存储和 API 统一 UTC。
- 决策列展示回复概率、跳过、拒绝或失败；旧消息未知决策显示“—”。状态列区分仅接收、决策中、不回复、生成中、发送中、已回复、拦截和失败。详情展示输入、决策、响应及输出确认，保存当时阈值和门控结果；用量只展示服务端实际返回值，不估算金额或伪造理由。仍在处理的详情每秒做一次有超时的状态读取，隐藏或关闭时停止；版本号防止旧结果覆盖新状态。

## 记录与隐私

`onEvent` 在 Runtime 去重后、规则过滤前写入独立的 `MessageLogStore`，因此不回复的消息也能留档。宿主 SQLite 实现保留最近 10000 条，唯一键为渠道、账号、会话和事件 ID。重启后日志仍可查询，同一保留窗口内的重投递不重复写入；已淘汰记录不再提供持久去重保证。

数据保存在 `.hina/messages.sqlite`，权限 `0600`，所在私有目录 `0700`，被 Git 和 Biome 强制忽略。它包含用户明确要求记录的消息正文、平台标识符、图片访问地址及模型响应，属于本机私有数据；不应公开分享或上传。日志 API 不读取或返回凭据，终端只打印状态和计数。

仅监听 `127.0.0.1:3410`，无公网绑定、无 CORS 放行。消息 API 只读：`GET /api/messages` 查询、`GET /api/messages/:sequence` 读取单条；分页参数经运行时校验，查询使用参数化 SQL。模型设置另有要求 Origin、JSON Content-Type 和 CSRF nonce 的写入与连接测试 API，见 [模型设置](./LLM.md)。`contentType=media` 是兼容旧查询参数的新增筛选值。`GET /api/events` 只发送 `ready/changed/status` 通知，不包含正文或标识符，最多同时 8 个连接，未消费通知合并后通过完整查询补齐。停止服务与客户端取消会释放订阅、流和心跳计时器。静态路由不能读取任意本地文件，当前不提供远程访问或多用户认证。

SQLite Schema v2 事务升级旧日志，新增处理结果与版本列，原消息和条数保持不变。启动后仅将遗留的处理中状态标为中断或发送未确认，不自动重试。这些观察记录不构成可恢复 Execution。

这只是消息观察记录，不是长期记忆、角色状态、可恢复 Execution 或持久审批；重启不会重放消息或恢复回复关联。开启日志之前未保存的消息不能补录。

## 图片预览边界

展开消息时，浏览器按消息序号与附件下标请求本机代理，不直接加载外部图片。代理只从已保存事件取得 URL，允许的精确域名为 `multimedia.nt.qq.com.cn`、`grouppro.grouppro.qq.com`、`c2cpicdw.qpic.cn`、`gchat.qpic.cn`；必须使用不带凭据或自定义端口的 HTTPS 地址，不跟随重定向。

每张最多 8 MiB、10 秒，最多同时读取 4 张。读取时校验真实字节签名，只预览 PNG/JPEG/GIF/WebP/AVIF，不执行 SVG/HTML。过期链接、超限、未知域名或下载失败显示可重试错误，消息记录仍保留。图片按需读取，不持久化二进制，所以长期保存的记录可能因 QQ 链接过期而无法预览；当前不宣称图片归档能力。请求和等待可取消，关闭宿主时一并取消。
